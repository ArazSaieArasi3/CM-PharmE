# CM PharmE 2.1 Ontology Requirements Specification

Current document version: **[0.2.0](0.2.0/ORSD.md)**, 21 October 2026.

The 0.2.0 technical consolidation records 24 overlap dispositions, eight scoped specializations, 83 acceptance contracts and the corrected scoped R-BA-02 mapping. The document is ready for one author content review before a 1.0.0 specification freeze. Independent expert acceptance and complete ontology validation remain separate tasks.

The [0.1.0 archive](0.1.0/ORSD.md) is preserved unchanged.

This is a reviewable requirements baseline for the 2.1 research candidate. The document version is independent of the ontology version. It does not declare an ontology release or close the semantic review gates.

The 83 tracked rows are **not** a count of independently elicited, semantically nonoverlapping or approved requirements. They comprise 32 newly specified core/infrastructure rows, 39 imported working headings and 12 quality requirements. Thirteen local refinements remain attached rather than added to this count. Historical discovery and held-out inventories remain separate.

The accepted direction retains RM, PV, BA and DS as purposeful small ontologies. Detailed model acceptance remains open. Future document versions should preserve identifiers, record merges and deferrals, and link each accepted requirement to its current model, constraints, answer oracle and execution evidence.
