# CM-PharmE 2.0 Human Review Entry Point

This file is a temporary human-review entry point for the V2 conceptual baseline.

The primary concept-provenance review artifact is `human-review-concept-provenance-matrix.md` in this directory. It is designed to let a human reviewer inspect each V2 concept against:
- V1 lineage;
- V2 working definition and OntoUML stereotype;
- admitted dataset / authoritative-source evidence;
- non-dataset literature, ontology, and methodological support;
- formal V2 implementation location;
- explicit evidence gaps or bounded claims.

This review package is V2-only. It does not modify CM-PharmE 1.x or the reviewer-facing `main` branch.
