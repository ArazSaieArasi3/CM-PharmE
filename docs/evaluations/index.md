# Evaluation

CM-PharmE evaluation is designed as a layered architecture. The reusable methodology is separated from version-specific evidence and results.

Planned layers include syntax validation, logical consistency, structural validation, ontological grounding, expert/semantic validation, data and mapping validation, competency questions, application validation, and research reproducibility.

## Available version-specific evaluations

- [CM-PharmE v1.0.0 — Structural Extraction Audit](v1.0.0-structural-audit.md): descriptive statistics, source-model anomalies, extraction quality, and B2 documentation assessment.

The B2 structural audit is intentionally scoped below a full ontology/evidence evaluation; later batches will add formal reasoner checks, expert evidence, competency-question results, mapping validation, and reproducibility packages.
