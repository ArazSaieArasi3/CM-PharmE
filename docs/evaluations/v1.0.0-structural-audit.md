# CM-PharmE v1.0.0 — Structural Extraction Audit

## Scope

This audit evaluates the B2 knowledge-model extraction and documentation layer built around the immutable v1.0 source artifacts. It is **not** a substitute for formal ontology validation, expert evaluation, competency-question testing, or data validation, which belong to later evaluation cycles.

## Extraction basis

1. Draw.io/XML source as the primary authority for concept labels, stereotypes, relation labels, relation categories, source/target endpoints, and diagram provenance.
2. Historical OWL/RDF/XML as a secondary cross-check only, because it was auto-generated from the diagram and contains converter artifacts.
3. The five-domain decomposition documented in the CM-PharmE research manuscript is used to curate primary and cross-domain mappings.

## Detected source-model issues

### 1. Duplicate concept with stereotype conflict
`Enterprise Governance Relator` occurs twice: once as `relator`, once as `mode`. The canonical registry uses one stable ID (`CMPE-C0025`) and retains `relator` while explicitly recording the conflicting occurrence.

### 2. Duplicate relation occurrence induced by the duplicated concept
`Organizational Stakeholder → Enterprise Governance Relator` / `is mediated by` occurs twice in the graphical source. It is represented as one canonical relation (`CMPE-R0002`) with source-occurrence count 2.

### 3. Mediation-direction wording anomaly
`Ecosystem Actor → Strategic Partnership Agreement` appears as both `mediates` (`CMPE-R0011`) and `is mediated by` (`CMPE-R0027`). Both are retained; formal semantic-direction review is required before normalization.

### 4. Generic or awkward lexical relation labels
The source labels `material relation` and `constraints` are preserved. Later terminology review should determine domain-specific labels and whether `constraints` should be normalized to `constrains`.

### 5. Historical OWL converter pollution
The auto-generated OWL includes cardinality text (`0..*`, `1`, `1..*`, `2..*`) and relation-label text as classes, and generated property names with numeric suffixes. These converter artifacts are deliberately excluded from the canonical B2 concept/relation registries.

## Remaining structural work

1. Transcribe and validate all relation cardinalities from the source diagram.
2. Create canonical formal definitions and persistent IRIs for concepts and relations.
3. Re-engineer the ontology from the canonical registries rather than from diagram-label conversion.
4. Resolve flagged stereotype and relation-direction anomalies.
5. Validate the formal ontology and mappings with automated and expert evaluation procedures.
