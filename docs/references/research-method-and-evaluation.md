## Reference-use policy

The papers remain the authoritative source for the exact research narrative in which these references were used. The repository cites only references that directly support reusable methodology, evaluation logic, ontology grounding, or downstream interpretation. Additional domain-literature references should be added to repository documentation only when they support a specific model decision, evidence record, mapping, or application claim.
