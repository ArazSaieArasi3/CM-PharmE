## Semantic Review Flags

1. **Enterprise Governance Relator stereotype conflict:** the source diagram contains two occurrences with the same label, one marked `relator` and one marked `mode`. The normalized registry retains one stable concept as `relator` and records the conflict.
2. **Duplicate mediation occurrence:** the duplicated governance-relator node produces two exact `Organizational Stakeholder → Enterprise Governance Relator` source occurrences; they are represented as one canonical relation with provenance count 2.
3. **Strategic Partnership Agreement mediation direction:** `Ecosystem Actor → Strategic Partnership Agreement` appears with both `mediates` and `is mediated by`. Both are preserved pending formal semantic-direction review.
4. **Generic/awkward relation wording:** `material relation` and `constraints` are retained verbatim from v1.0 and flagged for later terminology normalization rather than silently edited.
5. **Converter pollution in historical OWL:** cardinality labels and some relation labels were converted into classes; these are excluded from the canonical concept registry.
