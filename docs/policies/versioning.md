# Versioning Policy

CM-PharmE uses semantic versioning as a research-model convention:

- **PATCH**: metadata, documentation, typo, or non-semantic corrections that do not change model meaning.
- **MINOR**: backward-compatible semantic additions or extensions, such as adding concepts or relations without invalidating the established model contract.
- **MAJOR**: incompatible or substantial semantic restructuring, including major reclassification, domain restructuring, or changes that invalidate prior assumptions.

A publication event does not by itself determine the model version. Version numbers represent change in the model and its formal semantics.

Each stable release should have an immutable snapshot and manifest.
