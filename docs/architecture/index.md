# Architecture

CM-PharmE is organized as a layered research knowledge repository:

1. Conceptual Model
2. Semantic / Formal Ontology
3. Foundational Ontology Grounding
4. Data & Evidence
5. Mapping & Traceability
6. Evaluation
7. Research & Methodology
8. Applications & Consumption

Future architecture views will make the relationships between these layers explicit and traceable across releases.
