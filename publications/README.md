# Publications

This registry links scholarly publications to the CM-PharmE model state, research method, ontology state, and evaluation evidence associated with each study. Publication records provide scholarly provenance; the repository remains the evolving artifact/evidence record rather than a reproduction of manuscript prose.

## Research lineage

The published paper records the initial conceptual contribution. The later manuscript builds on that foundation without automatically creating a new semantic model version. The repository preserves both stages and distinguishes historical publication claims from current repository verification status.

See [Publication-to-Repository Traceability](../docs/research/publication-to-repository-traceability.md) and the [Final Evaluation Report](../docs/evaluations/b4-final-evaluation.md).

## Repository/publication navigation

Use the **publisher link** when you want the published scholarly article itself. Use the **repository record** when you want model-version association, research provenance, evaluation status, and links to the evolving CM-PharmE artifact.

## Metadata policy

Publication status, DOI, publisher URL, indexing, acceptance/publication dates, and other bibliographic identifiers are included only when they are supported by the publication record or independently verified. Missing metadata is not inferred.
