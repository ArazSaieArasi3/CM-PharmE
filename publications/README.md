# Publications

This registry links scholarly publications to the exact CM-PharmE model release, ontology state, concept/relation set, mappings, and evaluation evidence used by the study whenever those details are available.

## Records

- [Initial CM-PharmE publication record](ieee-2025/README.md) — associated with historical model release `v1.0.0`.
- Journal-oriented CM-PharmE work — metadata and final release mapping to be added after verification and model-version determination.

Publication metadata is recorded conservatively: DOI, publisher URL, indexing, acceptance/publication status, and other identifiers are included only after verification.
