# CM-PharmE Ontology

This directory is the future home of the formal CM-PharmE ontology lifecycle. The v1.0.0 OWL file is preserved under `releases/v1.0.0/ontology/` as a historical generated artifact.

The target architecture separates a canonical ontology source from generated distributions such as OWL/RDF/XML, RDF/XML, JSON-LD and N-Triples, and will support validation, upper-ontology alignments, mappings, SPARQL competency queries, and future SHACL constraints.

**Important:** the historical auto-converted OWL file is not treated as the cleaned canonical ontology source for future versions.
