# CM-PharmE 2.1.0 — M1 Provenance Core

This distribution provides an isolated four-class/two-property provenance
profile, explicit opt-in data admission and the unchanged Q21-01 query.
The selected M001–M004 integration is tested on seven synthetic copied-W6
records. Source manifest, licenses, documentation and frozen witnesses are
included with their original directory layout under source/.

Read [the support contract](source/v2/release/2.1/support/0.1.0/README.md),
[reproduction instructions](REPRODUCE.md), [NOTICE](NOTICE.md) and
[release citation](CITATION.cff). Historical source records describe their
contract-freeze state; this archive's preparation/checks do not themselves
assert publication. The GitHub release page supplies live publication status.

The distribution version is 2.1.0 and the contained profile version is 0.1.0.
Source/CITATION.cff remains the historical 1.0.0 citation. Full P3 files are
reference-only derivation/hash inputs, not a supported complete ontology.
Raw RDF retains row-number rdf:value assertions; the strict OWL view omits
only those assertions and reports their count. It is not lossless conversion.

The source-policy acceptance remains 1/4 and historical ORSD acceptance 0/83.
No new expert responses, full-source ingestion, all-36-mapping/full-native
acceptance or product effectiveness is claimed. Later work remains tracked.
