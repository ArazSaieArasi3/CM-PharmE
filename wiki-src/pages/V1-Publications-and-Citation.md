## Citation discipline

Use the machine-readable [CITATION.cff](https://github.com/ArazSaieArasi3/CM-PharmE/blob/main/CITATION.cff) and cite the specific CM-PharmE semantic release used whenever possible.

For reproducible work, also record the repository ref or release artifact used.

## Publication versus repository evidence

The scholarly paper/manuscript and the repository have different roles:
- the publication communicates the study and contribution;
- the repository preserves versioned model artifacts, formalization, evidence, executable validation and traceability.

Later repository verification must not be retroactively represented as if it had been reported in an earlier publication unless the publication actually contains it.

## Metadata policy

DOI, publication/acceptance status, dates and indexing information should be stated only when supported by the publication record or independently verified.
