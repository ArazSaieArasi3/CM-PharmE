# CM-PharmE Wiki

CM-PharmE is a versioned, ontology-grounded research program for modeling and investigating the pharmaceutical ecosystem. This Wiki is the human-readable documentation layer for the stable CM-PharmE 1.x baseline and the evolving CM-PharmE 2.0 research line.

> **Current Wiki baseline:** WB-2026.09.1  
> **CM-PharmE 1.x:** Stable  
> **CM-PharmE 2.0:** Stable-to-date / Evolving  
> **Important:** V2 is not final. Only currently stable evidence is documented as established.

## Current synchronization status

CM-PharmE 2.0 documentation remains intentionally open to controlled updates. The current research-facing documentation is synchronized again after demonstrator evaluation, semantic stabilization and final research-release readiness when those milestones become available.

## Source-of-truth rule

The Wiki explains and connects the project. Semantic definitions, formal artifacts, evaluation results and current research status remain governed by the linked authoritative repository sources for the relevant version.
