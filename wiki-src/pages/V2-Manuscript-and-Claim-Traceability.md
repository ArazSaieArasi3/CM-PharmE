## Evidence-led manuscript rule

No substantive V2 result should appear in the manuscript merely because it is plausible or implemented. Each claim must map to:
- an evidence family;
- a repository artifact/result;
- an interpretation boundary;
- a manuscript location;
- a disposition: approved, bounded/narrowed, deferred or limitation.

## Traceability path

A strong manuscript claim should be auditable through:

**Manuscript statement → claim ID/disposition → evaluation family → result artifact → repository ref → limitation/boundary**
