## Primary improvement gaps

1. Reader-facing visual documentation is absent.
2. The implemented database lacks a logical ERD, physical ERD and complete table/field reference.
3. Ontology documentation lacks complete module/class/property reference depth.
4. Internal Gate/Wave/review terminology is too visible in normal reader-facing pages.
5. Operational metadata is dense at the top of many pages.
6. Tested tutorial/how-to coverage is limited.
7. Documentation profiles are not yet formally separated.

## Strong baseline areas to preserve

- scientific and semantic rigor;
- version/evolution traceability;
- evidence and source traceability;
- evaluation/reproducibility documentation;
- publication/citation guidance;
- navigation/findability;
- QA, controlled publication and reproducible archive.

## Scoring integrity rules

- Page count and word count are descriptive metrics, not quality by themselves.
- Diagram count does not receive quality credit without notation, semantic correctness and readability.
- Pending work receives no completion credit.
- Generated reference pages receive credit only if usable, linked and subordinate to authoritative semantic sources.
- Final scoring must use the same rubric version unless a formally versioned correction is approved with impact analysis.
