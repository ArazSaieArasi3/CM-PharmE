## Journey design rules

- A journey should start from a reader question, not a repository folder.
- The first two navigation steps should provide enough context to decide whether deeper technical material is relevant.
- Version-specific differences must be visible before a reader can accidentally mix V1 and V2 facts.
- Tutorial-style execution paths will be added under #239 without replacing these explanatory/reference journeys.
